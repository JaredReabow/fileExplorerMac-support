fileExplorerMac

Support for the sandboxed macOS folder browser.

Get help

Report a problem, ask a question, or request a feature through the public issue tracker. Include the macOS version, fileExplorerMac version, and the steps that led to the issue. Do not include passwords, private file contents, or other sensitive information.

Open the issue tracker Read the privacy policy

Before reporting

Update to the latest available version and retry the action. If a folder outside the app container is unavailable, reopen it with the app’s folder picker so macOS can grant access. Screenshots are helpful when they do not reveal private information.
